# Six-semester learning roadmap

**Proposed track:** Data science and applied machine learning. Build on the Python expense tracker to explore student spending patterns and evaluate simple forecasts.

**Current programme:** BCA in Artificial Intelligence and Data Science, semester 1. Current subjects are Mathematics, Computer Science, Python, Communication and Web Development.

| Semester | Skill focus | Project and measurable milestone | Career preparation |
| --- | --- | --- | --- |
| 1 | Python, lists, dictionaries, Git | Rebuild the menu for adding expenses and cover empty and repeated-category input with tests. | Explain a test failure and its fix in a two-minute demo. |
| 2 | SQL, schema design, HTTP | Store expenses in SQLite and verify that daily totals match the original Python reports on three sample datasets. | Prepare an annotated schema and one sample query for a portfolio review. |
| 3 | Data structures, algorithms, complexity | Implement five algorithms with edge-case tests. Compare a dictionary lookup with a linear scan as input size grows. | Practise explaining the time and space costs of each solution. |
| 4 | Web development, APIs, accessibility | Add entry, list and summary views. Test keyboard navigation and input validation for each. | Ask two students to try the app and document their feedback. |
| 5 | Applied statistics and machine learning | Compare a rolling-average spending forecast with a last-week baseline on held-out weeks. Report mean absolute error and explain one failure case. | Review requirements for an entry-level cloud certification and complete two practice assessments. |
| 6 | Deployment, performance, team delivery | Measure report latency on 10,000 synthetic rows, investigate the slowest query and publish the before/after results. | Prepare a project walkthrough and submit five tailored internship applications. |

## Next three monthly targets

1. December 2026 — Add six automated tests for the Python expense tracker.
2. January 2027 — Design the database schema and implement three summary queries.
3. February 2027 — Connect a browser form to the database and demonstrate a complete add-and-view flow.
